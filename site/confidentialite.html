Confidentialité

Dernière mise à jour : 24/10/2026

Aucune collecte par HorsPC

HorsPC ne collecte aucune donnée personnelle : pas de formulaire, pas de compte, pas de mesure d'audience, pas de publicité, pas de cookie. Les polices et les jaquettes sont servies depuis le site lui-même ; aucune page ne charge de ressource depuis un autre domaine.

Préférence de thème

Si vous choisissez le thème clair ou sombre avec le bouton prévu, ce choix est enregistré dans le stockage local de votre navigateur (localStorage, clé horspc-theme). Il ne quitte pas votre appareil et n'est transmis à personne. Ce traceur, qui conserve un choix de personnalisation de l'interface demandé par l'utilisateur, est exempté de consentement au sens des lignes directrices de la CNIL sur les cookies et autres traceurs. Vous pouvez le supprimer en effaçant les données de ce site dans les réglages de votre navigateur.

Hébergement par GitHub Pages

Le site est hébergé par GitHub Pages. GitHub indique que « lorsqu'un site GitHub Pages est consulté, l'adresse IP du visiteur est journalisée et conservée à des fins de sécurité, que le visiteur soit connecté à GitHub ou non » (documentation GitHub Pages, section « Data collection »). Ce traitement relève de GitHub, Inc. : voir le GitHub General Privacy Statement.

Liens vers GitHub

Le lien de demande de retrait ouvre un formulaire de GitHub Issues : il faut un compte GitHub, et la demande est publique. Les données saisies sont alors traitées par GitHub selon sa propre politique de confidentialité.
